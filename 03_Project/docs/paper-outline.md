## Abstract

## 1. 서론
- 1.1 배경: 빌드 타임에 고정되는 렌더링 모드(CSR/SSR/SSG/ISR/Streaming SSR/Islands)
- 1.2 문제 제기: 최적 모드는 디바이스·네트워크·서버 부하의 함수
- 1.3 연구 질문 및 기여
  - RQ1 조건별 모드 우열이 실제로 갈리는가 (divergence)
  - RQ2 학습된 정책이 고정 모드·휴리스틱 베이스라인을 이기는가
  - RQ3 엣지 추론 오버헤드(TTFB < 2ms)와 캐시 효율을 유지하며 서빙 가능한가
- 1.4 논문 구성

## 2. 관련 연구
- 2.1 CSR vs SSR 성능 비교 연구
- 2.2 적응형 웹 전송 (adaptive loading, client hints, RUM 기반 최적화)
- 2.3 웹 성능 예측·ML 기반 시스템 최적화
- 2.4 오프폴리시 평가와 인과 추론 (counterfactual 문제)

## 3. 문제 정식화
- 3.1 컨텍스트 벡터 x, 모드 집합 M(r), 라우트별 실행 가능 모드
- 3.2 비용 함수 J(x, m) = QoE 비용 + λ·서버 비용
- 3.3 제약 최적화와 λ의 shadow price 해석 (dual ascent)
- 3.4 서로게이트 회귀 + argmin — 분류가 아닌 이유, top-1/top-2 마진과 전환 비용
- 3.5 라우트별 z-score 정규화의 필요성

## 4. 시스템 설계
- 4.1 전체 아키텍처: 5개 플레인 (SUT / 클라이언트 측정 / 부하 주입 / 데이터 / 학습·서빙)
- 4.2 벤치마크 애플리케이션(SUT): 단일 코드베이스 5모드 라우팅, 공유 컴포넌트 그래프
- 4.3 결정 계층(policy): 하드 핀(크롤러·결제/인증), 서킷 브레이커, infeasible 폴백 기록
- 4.4 엣지 서빙: `x-ugrp-bucket` 캐시 키 설계, origin-request 시점 추론, 번들 내장 트리
- 4.5 상관 ID 조인 — 데이터 무결성 경로
- 4.6 계획서 대비 설계 변경과 근거 (SageMaker/AppConfig/Firehose/ElastiCache 미채택, 랩 경로 무-CDN)

## 5. 실험 설계 및 데이터 수집
- 5.1 Full-factorial 격자: 디바이스 4 × 네트워크 5 × 부하 4 × 모드·캐시 상태 = 10,400셀 × 30반복
- 5.2 클라이언트 에뮬레이션: CDP 스로틀링과 Client Hints 주입, 실제 디바이스 캘리브레이션 서브셋
- 5.3 외생적 배경 부하: k6 VU 이진 탐색, 지속 부하 vs 버스트 캘리브레이션 편차
- 5.4 병렬 수집 인프라: 20샤드(SUT+k6+worker 삼중), 샤드 배정 규칙, 체크포인트·재개
- 5.5 재현성 통제: 이미지 다이제스트 고정, 버전·시드 기록, 조건 순서 무작위화, 격리(quarantine) 창
- 5.6 필드 무작위화(5–10%)와 성향 로깅

## 6. 학습 파이프라인
- 6.1 특징 벡터와 train-serve 정합성 (features.ts ↔ config.py)
- 6.2 레이블링: 웹 바이탈 QoE 비용, 서버 비용 측정 범위와 한계 (C_serve/C_store 미계측)
- 6.3 LightGBM 서로게이트 + pairwise 목적 함수
- 6.4 트리 증류와 서빙 게이트(check:tree) — 증류 깊이는 λ에 딸린 값이다(배포본 depth 12)
- 6.5 시간·라우트 그룹 분할, 누수 방지

## 7. 평가
- 7.1 평가 지표: QoE 비용, 서버 CPU, regret vs oracle, 모드 전환률
- 7.2 베이스라인: 고정 모드 5종, 프레임워크 기본값(Streaming SSR), 휴리스틱 규칙
- 7.3 조건별 divergence 분석 (RQ1)
- 7.4 정책 성능 및 λ 스윕 — QoE·비용 파레토 (RQ2)
- 7.5 오프폴리시 평가 (IPS/DR) 결과
- 7.6 서빙 오버헤드·캐시 적중률 (RQ3)
- 7.7 절제 실험: 정규화 유무, 특징군 제거, 트리 깊이, 서버 상태 staleness
- 7.8 검증 스크립트 결과 (dom·join·divergence·policy·determinism)

## 8. 논의
- 8.1 결과 해석과 실무 함의
- 8.2 위협 요인: 에뮬레이션 vs 실기기, 부하 캘리브레이션 드리프트, 단일 SUT 일반화, 서버 비용 미계측 항
- 8.3 조용히 실패하는 버그들과 방어 게이트 (봇 오분류, Client Hints 미주입, 특징 순서 드리프트, floating Promise)
  — 시스템 논문이면 본문, ML 논문이면 부록으로
